# التوأم الرقمي لمنظومة الإسعاف والطوارئ في مدينة الرياض

نموذج أولي (MVP) لهاكاثون: نموذج رقمي + محاكاة + دعم قرار، لمنظومة إسعاف وطوارئ افتراضية في الرياض.

> **بيانات محاكاة لأغراض العرض والتجربة.** جميع المستشفيات والمركبات والطرق والسعات مصطنعة، ولا تمثل بيانات تشغيلية حقيقية أو آنية.

## التشغيل

```bash
pip install -r requirements.txt
streamlit run app.py
```

لا يحتاج النظام إلى API مدفوع أو قاعدة بيانات أو تسجيل دخول. الاتصال بالإنترنت مطلوب فقط لبلاطات الخريطة
(CartoDB) ولخط الواجهة؛ وعند غيابه اختر «خريطة احتياطية (Plotly)» من الشريط الجانبي.

## البنية

```text
Python → النموذج الرقمي (data.py) → محاكاة SimPy (simulation.py)
       → خوارزمية القرار (recommendation.py) → لوحة Streamlit (app.py) → خريطة الرياض
```

| الملف | المحتوى |
|---|---|
| `data.py` | `generate_demo_data()`، `create_digital_twin()`، نموذج زمن الرحلة `RoadModel`، إضافة البلاغات |
| `recommendation.py` | `calculate_hospital_score()`، `recommend_hospital()` (30% سعة، 25% زمن، 20% تخصص، 15% طريق، 10% بعد الاستقبال) |
| `simulation.py` | `simulate_scenario()`، `simulate_what_if()`، `calculate_system_readiness()` |
| `app.py` | الواجهة العربية RTL: `render_map()`، `render_kpis()`، `render_hospital_capacity()`، `render_scenario_comparison()` |

## كيف تعمل المحاكاة

- كل بلاغ يُقسم إلى رحلات: مركبة لكل حالة حرجة، ومركبة لكل مصابَين من غير الحرجة.
- كل رحلة عملية SimPy: استقبال البلاغ ← اختيار أقرب مركبة متاحة (أو الانتظار) ← الوصول ← التثبيت ← اختيار المستشفى ← النقل ← التسليم.
- الاستراتيجيات: **أقرب مستشفى**، **أعلى قدرة استيعابية**، **التوزيع المتوازن** (يعتمد نتيجة التوصية مع تجنب تجاوز 75% إشغالًا وعقوبة تكديس).
- حالة بلا سرير تضيف تأخير تسليم (12 دقيقة) وتخفض الجاهزية.
- جاهزية المنظومة (0–100): 25% مركبات، 30% سعة المستشفيات، 15% الطرق، 15% عبء البلاغات، 15% زمن الاستجابة؛ وتُقاس بعد 25 دقيقة من البلاغ.

## عرض سريع (30–60 ثانية)

اضغط **تشغيل سيناريو تجريبي**: يُنشئ حادثًا كبيرًا (6 مصابين، 2 حرجة، ازدحام شديد، 5 مركبات متاحة، مستشفى جامعي تحت ضغط حرج، ومركز طبي بعناية مركزة جيدة)، ثم يعرض التوصية ويشغّل السيناريوهات الثلاثة ويقارنها. بعدها جرّب تبويب **ماذا لو؟**.
